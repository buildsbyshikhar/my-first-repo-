V2.1Deep Learning Training Lab

Flagship Training Lab

A single long-running lab that forces theory, implementation, evaluation, systems and research habits to connect. It is designed to grow with you rather than become one giant project on day one.

Lab 0 — Reproducible base

  • Git repository with README
  • Python environment + pinned dependencies
  • Config-driven experiments
  • Seed handling
  • Logging
  • Unit tests for core utilities

Lab 1 — From-scratch foundations

  1. Linear regression in NumPy.
  2. Logistic regression in NumPy.
  3. K-means.
  4. One-hidden-layer neural net with manual gradients.
  5. Compare your implementation with PyTorch autograd.

Deliverable: a technical notebook explaining the math and a clean Python implementation.

Lab 2 — PyTorch training

  • Dataset/DataLoader
  • Model module
  • Training/validation loop
  • Checkpointing
  • Mixed precision
  • Experiment logging
  • Profiling

PyTorch's current beginner sequence covers tensors, datasets/data loaders, transforms, models, autograd, optimization and saving/loading; use it as the implementation spine. citeturn0search4turn0search1

Lab 3 — CNN

  • Build a small CNN.
  • Establish a baseline.
  • Add augmentation.
  • Compare normalization choices.
  • Run one controlled ablation.

Track: accuracy/F1, training time, parameter count, peak VRAM and inference latency.

Lab 4 — Attention → Tiny Transformer

  1. Implement scaled dot-product attention.
  2. Add masking.
  3. Add multi-head attention.
  4. Add positional information.
  5. Add residuals + normalization + FFN.
  6. Train a tiny Transformer on a toy task.

Required explanation: derive the tensor shapes at every major step.

Lab 5 — Modern model adaptation

  • Use a pretrained model.
  • Compare prompting, retrieval and PEFT.
  • Try LoRA/QLoRA where appropriate.
  • Measure quality, latency, memory and cost.

Lab 6 — RAG evaluation

  • Create 100–300 test questions.
  • Track retrieval hit rate/recall.
  • Track answer correctness.
  • Track citation correctness.
  • Track faithfulness/groundedness.
  • Track abstention accuracy.
  • Measure latency and cost.

Lab 7 — Agent security

  • Tool calling
  • Explicit tool schemas
  • Least privilege
  • Sandboxing
  • Direct + indirect prompt-injection tests
  • Regression suite

Lab 8 — Research reproduction

  1. Select a paper that fits your compute.
  2. Write the hypothesis and baseline before coding.
  3. Implement/reproduce the core method.
  4. Record deviations from the paper.
  5. Run an ablation.
  6. Publish code, config, environment and report.

Lab 9 — Systems upgrade

  • Profile CPU/GPU/memory.
  • Find the actual bottleneck.
  • Optimize data loading.
  • Compare eager vs compiled execution where applicable.
  • Benchmark throughput/latency.
  • Document the tradeoff.

Current PyTorch materials include data-loading optimization, distributed training, serving, memory profiling and debugging, so systems work belongs in this lab rather than being postponed indefinitely. citeturn0search1

Final evidence checklist

  • Clean Git history
  • README that another person can follow
  • Reproducible environment
  • Training/evaluation scripts
  • Tests
  • Experiment logs
  • Metrics and error analysis
  • Ablations
  • Performance measurements
  • Short technical report
