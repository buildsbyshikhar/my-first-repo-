Source rule

Do not study five courses for the same topic. Pick one primary source, finish its exercises/projects, then use a secondary source to repair a specific gap.
Built as a practical 2026→2027 learning plan. Use one primary source per stage; use secondary sources only when you are stuck or need another explanation.
