AI/ML Deep Question Bank

Use this only after studying the corresponding roadmap stage. The goal is not memorization; the goal is being able to explain, derive, implement, break and improve systems.

How to use it

  1. Recall: define it.
  2. Explain: explain it without notes.
  3. Derive: show the math.
  4. Implement: code it from scratch.
  5. Debug: diagnose a broken implementation.
  6. Design: choose an approach under constraints.
  7. Research: propose and evaluate a change.

1. Zero Math & Algebra

  1. Why does dividing by a fraction multiply by its reciprocal?
  2. Convert between fractions, decimals, percentages and ratios without a calculator.
  3. Why does scientific notation help with ML-scale numbers?
  4. Solve a linear equation and explain every transformation.
  5. What does a function mean? Give domain/range examples.
  6. Why do exponentials appear in growth, probability and ML?
  7. Derive the basic logarithm laws from exponent rules.

2. Discrete Math

  1. Prove a statement by induction.
  2. Give a direct proof and a contradiction proof of a simple statement.
  3. What is a relation? What makes a relation an equivalence relation?
  4. Why are graphs useful for representing computation?
  5. Define a DAG and explain why topological ordering exists.
  6. Derive the growth of a simple recurrence.
  7. Explain O, Ω and Θ with concrete examples.
  8. Why does asymptotic analysis ignore constants?

3. Python & Software

  1. Explain mutable vs immutable objects in Python.
  2. When would you use a list, tuple, set or dict?
  3. Write a generator and explain why it can save memory.
  4. Design a package structure for a small ML project.
  5. How would you test a preprocessing function?
  6. How would you debug a model that suddenly returns NaN?
  7. What should be logged during a training run?

4. DSA & Algorithms

  1. Implement a dynamic array conceptually. What makes append amortized O(1)?
  2. Implement a stack and queue and state their operations' complexities.
  3. How does a hash table handle collisions?
  4. When is a heap better than a sorted array?
  5. Implement BFS and DFS. When does each fit?
  6. Why does Dijkstra require non-negative edge weights?
  7. Explain topological sorting and give an ML/data-pipeline use case.
  8. Write merge sort and derive its complexity.
  9. Compare quicksort, mergesort and heapsort.
  10. How do you identify overlapping subproblems for dynamic programming?
  11. Write a DP solution and then reconstruct the chosen path/solution.
  12. Given a problem, justify your data structure choice before coding.

5. Core CS

  1. What happens when a Python program requests memory?
  2. Processes vs threads: what is shared and what is not?
  3. What is a race condition? Give a concrete example.
  4. Why does CPU cache matter for performance?
  5. Bandwidth vs latency: why do both matter to ML systems?
  6. What happens during an HTTPS request?
  7. Why do database indexes speed reads but add costs?
  8. What is a transaction?
  9. Why can a DataLoader become a training bottleneck?

6. Classical ML

  1. Derive linear regression with MSE.
  2. Why does logistic regression use a sigmoid?
  3. Explain L1 vs L2 regularization.
  4. Why can leakage make a model look excellent?
  5. When is PR-AUC more informative than ROC-AUC?
  6. Why do trees handle nonlinear relationships naturally?
  7. Bagging vs boosting: what problem is each addressing?
  8. Explain K-means failure modes.
  9. Why does PCA depend on scale?
  10. How would you evaluate a severely imbalanced classifier?

7. Deep Learning

  1. Derive the gradient of a simple neuron.
  2. Explain the chain rule in backpropagation.
  3. Why can deep networks suffer from exploding/vanishing gradients?
  4. Compare SGD, momentum and Adam.
  5. What does weight decay do?
  6. Why does initialization matter?
  7. BatchNorm vs LayerNorm: what is normalized and why?
  8. Why do residual connections help optimization?
  9. Implement a tiny neural network with manual backprop.
  10. Diagnose a training run whose training loss falls but validation loss rises.

8. CNNs / Sequence Models

  1. What does a convolution actually compute?
  2. How do stride and padding change spatial dimensions?
  3. What is a receptive field?
  4. Why does transfer learning work?
  5. Explain BPTT and why long sequences are difficult.
  6. Compare RNN, LSTM and GRU at a conceptual level.
  7. Implement a tiny CNN training loop.

9. Transformers / LLMs

  1. Why are Q, K and V separate?
  2. Derive scaled dot-product attention.
  3. Why divide by sqrt(d_k)?
  4. What does multi-head attention buy us?
  5. Why is causal masking required for autoregressive generation?
  6. What problem does positional information solve?
  7. Explain RoPE conceptually.
  8. What is the KV cache and why does it matter for inference?
  9. Pretraining vs fine-tuning vs RAG: when does each change the model/system?
  10. Explain LoRA and why it reduces trainable parameters.
  11. Quantization: what tradeoffs are introduced?
  12. Design an evaluation set for a small RAG system.

10. Generative AI / Multimodal

  1. Compare autoencoders, VAEs and GANs.
  2. What is the high-level idea behind diffusion?
  3. What is contrastive learning?
  4. How can image and text representations be aligned?
  5. What makes multimodal evaluation difficult?

11. Agents / Security / Reliability

  1. What are tools, state, memory and observations in an agent loop?
  2. How does indirect prompt injection differ from direct prompt injection?
  3. How can a retrieved document attack an agent?
  4. How would least privilege reduce agent risk?
  5. What should a regression suite test after changing a RAG pipeline?
  6. How do you measure citation correctness and abstention accuracy?

12. Systems / MLOps

  1. What is the difference between latency and throughput?
  2. When does a model become memory-bound rather than compute-bound?
  3. What does mixed precision change?
  4. What problem does distributed data parallelism solve?
  5. When would sharding be necessary?
  6. What should an experiment tracker record?
  7. How would you reproduce a six-month-old experiment?

13. Research

  1. How do you identify a paper's actual contribution?
  2. What is a baseline and why is it necessary?
  3. What is an ablation?
  4. How would you reproduce a paper with limited compute?
  5. How do you distinguish an implementation bug from a weak hypothesis?
  6. Design an experiment with one independent variable and a defensible metric.
  7. How would you report a negative result?

Mastery rule

You pass a topic when you can: explain it simply, solve a fresh problem, implement a small version, debug a broken version, and connect it to a real AI system.
Built as a practical 2026→2027 learning plan. Use one primary source per stage; use secondary sources only when you are stuck or need another explanation.
